# clambback Brand Assets

This directory contains the brand icons for `clambback`.

## Files

- `clambback-official-logo.png` - official generated logo for GitHub and project presentation.
- `clambback-squircle.svg` - default app icon: flat Bauhaus-style monoline backpack with a red buckle dot on a paper squircle (no wordmark).
- `clambback-squircle-1024.png` - 1024x1024 PNG render of the default icon.
- `clambback-squircle-classic.svg` - previous glossy macOS-style backpack icon, kept as an alternate.
- `clambback-squircle-classic-1024.png` - 1024x1024 PNG render of the classic icon.

## Usage

- Use `clambback-official-logo.png` as-is for the repository README and project profile surfaces. Do not crop out the backpack, alter the wordmark, add shell/clam motifs, or add C++ shield decorations.
- Use `clambback-squircle.svg` (or the PNG render) by default for app grids, product cards, favicon-style placements, and anywhere a square icon tile is needed.
- Default icon palette: ink `#1a1a1a`, paper `#f4efe6`, brand red `#e11d2f`. Keep it flat (no gradients or shadows) and keep the 5-unit stroke on the 128 grid.
