# clambback Brand Assets

This directory contains the brand icons for `clambback`.

## Files

- `clambback-official-logo.png` - earlier generated logo with wordmark, kept for reference.
- `clambback-squircle.svg` - default app icon: flat Bauhaus-style monoline backpack with a red buckle dot on a paper squircle (no wordmark).
- `clambback-squircle-1024.png` - 1024x1024 PNG render of the default icon.
- `clambback-squircle-classic.svg` - previous glossy macOS-style backpack icon, kept as an alternate.
- `clambback-squircle-classic-1024.png` - 1024x1024 PNG render of the classic icon.

## Usage

- Use `clambback-squircle.svg` (or the PNG render) for the repository README, project profile surfaces, app grids, product cards, favicon-style placements, and anywhere a square icon tile is needed.
- Default icon palette: ink `#1a1a1a`, paper `#f4efe6`, brand red `#e11d2f`. Keep it flat (no gradients or shadows), do not add shell/clam motifs or C++ shield decorations, and keep the 5-unit stroke on the 128 grid.
